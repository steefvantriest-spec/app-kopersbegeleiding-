# Downloads

## Brochure

Op de laatste publieke pagina staat een **leadformulier** (geen directe download
meer). Bezoekers vullen naam + e-mail (+ optionele feedback) in; de aanvraag
wordt opgeslagen in Supabase-tabel `brochure_requests`.

Er is (nog) **geen automatische e-mailverzending** ingericht in de app. De
brochure moet daarom **handmatig** worden verstuurd naar binnenkomende aanvragen.
Gebruik hiervoor dit bestand:

    assets/downloads/brochure-des.pdf

Vervang alleen dit bestand om de brochure te updaten — zelfde bestandsnaam
aanhouden.
